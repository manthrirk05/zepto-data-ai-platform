# Zepto Data & AI Platform

An end-to-end AI/ML engineering project built as a single repository.

## Project Modules

### Module 1 — Data Pipeline

Folder:

`data_pipeline/`

This module performs:

- Web scraping
- Data cleaning
- GBP to INR conversion
- SQLite database creation
- SQL analysis
- Pandas verification

### Module 2 — Analytics Pipeline

Folder:

`analytics/`

This module performs:

- Data profiling
- Missing-value analysis
- Outlier analysis
- Exploratory Data Analysis
- Feature engineering
- Classification
- Regression
- Model comparison

### Module 3 — Support Assistant

Folder:

`support_assistant/`

This module builds a RAG-based support assistant using:

- Document chunking
- Embeddings
- ChromaDB
- LangGraph
- FastAPI
- Structured JSON responses
